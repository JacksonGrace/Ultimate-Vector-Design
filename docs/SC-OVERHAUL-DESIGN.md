### 1.2 The roll-free axis (D2)
Every element's rotation axis is fixed at its ENTRY against the LEVEL frame of the SHARP chain (§1.5), never read from the rolled body frame. Entry tangent T0 (unit), `horiz2 = 1 − T0.y²`:
- `ul = (−T0.y·T0.x, horiz2, −T0.y·T0.z).normalize()` = Y − (Y·T0)T0 (bankOf's `ul`, ScIntegrator.java:430; `bankOfTU` FVDIntegrator.java:121-126); `rl = ul × T0` (the project's R = U × T).
- PLANAR axis `a = cos d·ul + sin d·rl` (unit, ⊥ T0), world-fixed for the whole element; `Ω/m = −k(s)·a`. Initial turning direction `N = T0 × a` (at d = 0: N = T0 × ul = −rl = left ⇒ +κ = LEFT).
- HELICAL: `Ω/m = −c_h(s)·cos β(s)·Y + β'(s)·h(T)`, `h(T) = (−T.z, 0, T.x)/|T_xz|` = GeoIntegrator.omegaFor's ypGlobal recipe (GeoIntegrator.java:122-136: `base = (0, −psR, 0) + h·thR/len`, `len ≤ 1e-6 ⇒ R.scale(−thR)` — the SAME fallback here); `β'(s) = (β1−β0)·f'(u)/L`. Y = the generation frame's vertical = the DESIGN vertical (canonical generation, TrackCompiler.java:449-458; spec L82 accepted).
- Roll: the lane (§2) only twists U about T after/within each step; it never enters `a`, `Y` or `h`. STRAIGHT: Ω/m = 0.
- VERTICAL-ENTRY rule (`horiz2 < HELIX_VERT_EPS`, the bankOf hold-off): no level frame — a PLANAR element inherits the previous element's roll-free end frame (`ul := U_rf(L_prev)`, `rl := R_rf(L_prev)`; element 0 after a vertical seam: the entry orientation's own U, R); editing its `dir` is refused with `DIR_INHERITED_WHY` (§1.8): §4.6's dir row refuses it, the Direction box (§6.2 rows 4-6, Planar column) grays with it as a STRUCTURAL case (§6.3) and the Direction ring does not build (§6.5). A HELICAL element cannot be CREATED or type-changed-into at a vertical entry (`HELIX_VERTICAL_WHY`, §1.1); if an upstream edit later makes an existing helix's entry vertical the compile uses the `h → −R` fallback and keeps going (deterministic, no sentence — nothing was clicked).
- `LEGACY_BODY_AXIS` (`static final boolean`, `-Dfvd.sc.legacyAxis=1`, one stage only, R2): true = today's law — `a` read per RK4 stage as `cos d·U + sin d·R` of the CURRENT body frame (ScIntegrator.java:116-117, :259-260 arithmetic order kept verbatim), blends lerp body components; HELICAL elements ignore the switch.

## 4. ScSolve: the kinematic solver, locks, interactions math
Pure Java (`uvd.ScSolve`, no JavaFX), the ONE solver every surface calls — ball, rings, arrows, boxes, ghost, insert, change-type, delete, align, closure, group move (PLAN §3 R6). Runs ONCE per event, never inside compile/rebuild (PLAN §2.3 B-iter-7); reads the SHARP element chain + the current `TrackCompiler.Span` data (the `Bound` record, §1.4.3); writes plain element fields. Binding decisions: D1, D2, D6, D9, D10, D13, D14, D15, D16, D17, D19, D21, D22, D26, D28. Conventions: internal heading `atan2(−T.z, T.x)`; +κ at dir 0 turns rider-LEFT (D187); the UI negates heading at its boundary (D186) — ScSolve is internal-sign throughout. Names and constants are §1.1's: `KAPPA_MAX` (written κ_max below; radius floor 0.1 m, DesignIO.java:966), `MIN_ELEM_LEN` (GraphEditor.java:10149), `KAPPA_INF`, `B1_MAX`, `HELIX_VERT_EPS`; c_h = a helix's plan curvature (stored in k0/k1). Robotic arms (spec L118): a chain of constant-curvature arcs is the piecewise-constant-curvature continuum-robot model — forward kinematics is the product of exponentials, one-segment position IK is closed form and two-segment full-pose IK is the biarc family (one free parameter, fixed by rule); general n-segment IK with limits is numeric, exactly what the spec forbids — so the useful import is the DOF classification (which locks over-constrain) and the single-absorber discipline.

### 4.2 Frames — world → canonical ONCE per event; the predictor
`SectionFrame.of(result, piece, sec)` = `{psi, canon}` of the section ENTRY (the previous Span's `exitPsi/exitCanon`, TrackCompiler.java:62-75, 508-510; section 0 of a piece with `Coaster.autoFollower(p)`: `{psi, canon}` = the UPSTREAM span's exit pair and `tilt` = that span's `exitTilt` (the IDENTITY object behind an untilted upstream; INHERITED behind a conflict-tilted one — the §3.5 A1 compile branch as merged in D259.1b's run-3 review); section 0 of every other piece — a locked or non-automatic follower, a bridged-in piece, a run head: the piece's canonical pair + its conflict/follow tilt), `tilt` (conflict/follow tilt, identity object when none), `postShift` (TrackCompiler.java:1164-1172), `entryW`. Law: `x_c = rotY(−psi)·tilt⁻¹·(x_w − postShift − entryW)`, tangents the same without the translation — the exact inverse of `placeLine`/`rotY` (TrackCompiler.java:186-221) + `tiltSample` (:854-878). ### 4.7 Lock model (D16) — data + DOF budget
`locks` = §1.1's bits {LEN, K0, K1, TURN, DIR, HEAD, ELEV, X, Y, Z, B1}; the window SHOWS the active chart's padlocks (local K0/TURN/DIR; global HEAD/ELEV/LEN) + X/Y/Z + K1/B1; a toggle keeps every set lock as a constraint, the hidden chart read-only; an orientation lock on a STRAIGHT is stored on it and applied to the previous curve (§4.5). ### 4.8 The AFTER rule — `absorbAfter` (ONE absorbing curve, orientation only, κ kept)
Input: node k's new exit `(p', T')` vs the old `(p, T, T2 = the old exit tangent of the absorber-to-be)`. Edits keeping T (L, κ at fixed Θ/dir, a straight's length) absorb nothing: downstream translates by `p' − p`. Else walk forward: straights re-aim to T' and keep ℓ; the FIRST curve c > k with TURN or DIR unlocked (both unlocked: the full restore below; one locked: the partial rows) restores its OLD exit tangent T2: `a ∝ T_in' × T2`, `Θ = atan2(|T_in' × T2|, T_in'·T2) + 2π·k_old`, `dir = atan2(a·R_in', a·U_in')` in c's new LEVEL frame (D2 — the plane reference is a function of T, so restoring T restores every later axis: the absorb is COMPLETE, verify/C-2 M2), κ KEPT, `L = Θ/|κ|`; κ = 0 (`|κ| < KAPPA_INF`): hold L and set `κ = Θ/L` (§4.4 I2's rule); everything after c translates by c's exit delta. Floor: `L < MIN_ELEM_LEN` ⇒ `L := MIN_ELEM_LEN`, `κ := Θ/MIN_ELEM_LEN` signed through zero (the ONE place the absorb changes κ, PLAN §2.4). Antiparallel (`T_in'·T2 < −1 + 1e-12`): keep dir, Θ = π + 2πk. Partially locked c: DIR locked → Θ = angle from T_in' to T2's projection on the plane ⊥ a; TURN locked → a chosen in the plane ⊥ T_in' hitting the cone point nearest T2; the RESIDUAL rotates the rest rigidly — a free-but-locked absorber leaving a residual posts `absorbResidualWhy(c)` ONCE (`residualRot`; ONE absorber, no cascade — a per-curve cascade, also closed form, only after feel-testing, PLAN §3 R12). No curve after k = expected behavior, NO sentence: nothing absorbs, the section exit rotates, downstream sections follow by contract (the auto seam re-aims; a locked seam shows carets). Helix as c: pitch-linked absorbs heading only (`Δψ := heading gap`, `L_h = Δψ/c_h`), elevation residual posted; unlinked: `b1 := elevation(T2)` too. A blend-length drag never runs the absorb; its δ against a locked downstream X/Y/Z is documented in §7.8. Corner: a LOCAL rate roll lane sees the absorbed rotation's body twist as a bank change — documented, not fixed.

### 8.7 Closed-tail edit rule (D22, PLAN C13)
